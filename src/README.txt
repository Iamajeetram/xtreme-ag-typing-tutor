AG Typing Tutor — Efficiency Test Update

INSTALL
1. Back up your current src/main.js.
2. Replace src/main.js with this ZIP's main.js.
3. Copy this ZIP's public/efficiency-bank folder into the project's root public/ folder (merge if public already exists). Final path: <project>/public/efficiency-bank/WORD_EN/WORD_EN_001.json.
4. Keep learning-content.js and all other existing files unchanged.
5. Restart Vite (Ctrl+C, then npm run dev) and hard refresh Safari.

CONTENTS
- 160 JSON files / 2,400 questions total: 600 each for Word English, Word Hindi, Excel English and Excel Hindi.
- App language selects the question bank language.
- Each Word/Excel screen has a question sidebar, Office-inspired ribbon/workspace, task instructions, check-answer scoring, per-check feedback, next task and local saved scores.
- Earlier consolidated main.js changes are retained, including the hidden Exam Typing Test and Exam Rules sidebar entries and comprehensive typing-result report.

LIMITATION
This is an Office-style simulator, not the desktop Microsoft Office applications. Scoring checks supported formatting controls, checked requirements and spreadsheet formulas/expected values. Some advanced Word properties and Excel formulas from the bank are not fully emulated; unsupported checks are shown as unsupported/not met rather than claimed as officially correct. Formula preview supports common SUM, AVERAGE, MAX, MIN, COUNT and simple arithmetic formulas.
